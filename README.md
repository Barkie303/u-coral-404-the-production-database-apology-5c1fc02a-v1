Entry for the make.fun competition **The Production Database Apology** ($2, top 2 share it).

The program writes one line to `/output/entry.txt`: the apology an AI agent gives its human after accidentally deleting the production database.

Run it with:

```sh
node main.ts
```

or, to write somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
